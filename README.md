\# PROMETHEUS-X



AI-powered PCB inspection system combining YOLO-based component detection and PatchCore-based anomaly detection.



\## Features



\- PCB image upload

\- Live camera input

\- YOLO component detection

\- PatchCore anomaly detection

\- Anomaly heatmap and overlay visualization

\- Anomaly region localization

\- Experimental severity assessment

\- Model confidence calibration analysis



\## Technologies



\- Python

\- Flask

\- OpenCV

\- YOLO

\- PatchCore

\- HTML, CSS, JavaScript
